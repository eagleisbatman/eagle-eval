# Eagle Eval Documentation

This folder contains focused, high-signal guides designed for excellent developer experience.

## Recommended Reading Order

1. [Installation Guide](installation.md) — Get Eagle Eval on your machine first (especially important while it's not on PyPI).
2. [Getting Started](getting-started.md) — The fastest path using coding agents.
3. [North Star + Resolution Policy](north-star-resolution-policy.md) — The single most important conceptual section.
4. Choose your environment:
   - [Grok Build](using-with-grok-build.md)
   - [Claude Code](using-with-claude-code.md)
   - [Codex](using-with-codex.md)
5. [Multi-Agent & Sequential Workflows](multi-agent-sequential-workflows.md) — For complex agent systems.
6. [Agent Prompt Templates](agent-prompt-templates.md) — Ready-to-use prompts for Grok, Claude Code, and Codex (very useful after installation).

## Philosophy (0.2.0)

These docs were written with one goal: to make Eagle Eval feel *excellent* the moment a developer or coding agent starts using it.

The focus is on the parts that actually move the needle:
- Goal-first thinking over generic metrics
- Honest diagnostics
- Powerful comparison of orchestrators vs sub-flows
- Custom scorers tied to real North Stars
- First-class support for being driven by Claude Code, Codex, and Grok Build

Short, high-signal documents > exhaustive reference material.

## Contributing to Docs

If you improve these guides, keep the tone practical, example-driven, and respectful of the user's time. Short, excellent documents beat long reference material.
